# Activity Day to Day

Gestionnaire d'activités quotidiennes pour la famille.

## Description

Ce projet contient des outils pour organiser et suivre les activités quotidiennes de la famille, incluant la gestion des tâches.

## Contenu

- **tableau-taches-familiales.html** : Tableau interactif pour la répartition des tâches familiales

## Utilisation

Ouvrez simplement le fichier HTML dans votre navigateur pour accéder au tableau des tâches.
